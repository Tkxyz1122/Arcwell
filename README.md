## 开始使用

**安装版（推荐）**：点击“下载安装版”，下载的是 Setup.exe 安装程序，**无需手动解压**。双击后按安装向导选择位置并完成安装。

**便携版（可选）**：点击“下载便携版”，解压后打开其中的 Arcwell 文件夹，双击 Arcwell.exe。请保留整个文件夹，移动时一起移动。

**检查更新**：打开应用，点击左下角齿轮 → 应用更新 → **检查更新**。发现新版本后，在应用中下载并安装。

## 整理每一个值得留下的网页

- 收藏网址、修改名称、记录备注和添加星标。
- 按层级文件夹分类，启动默认折叠，长名称悬停显示全称。
- 左键单击打开网页，菜单与星标按钮独立操作，悬停高亮。
- 支持搜索、最近添加、星标筛选、列表与网格视图。
- 导入浏览器 HTML 收藏，可选择合并添加或完全覆盖。
- 收藏保存在本地，自动同步应用目录与自选目录中的 HTML 备份。

快捷键：**Ctrl+K** 搜索，**Ctrl+N** 添加网址。
